# TaskFlow

**Controle de Tarefas Corporativas**

Projeto acadêmico desenvolvido pela Equipe 01 para a disciplina de **Requisitos, Modelagem e Análise de Dados**, do curso de Engenharia de Software da Católica SC.

## 1. Sobre o projeto

O TaskFlow é um projeto acadêmico desenvolvido para representar um sistema de controle de tarefas corporativas, permitindo organizar informações sobre colaboradores, tarefas, setores, atribuições e histórico de status.

O projeto contempla a identificação dos dados, regras de negócio, decisões de modelagem e estruturação dos modelos conceitual e lógico relacional.

O trabalho tem como foco a documentação e a modelagem de dados, não contemplando, nesta etapa, o desenvolvimento de um sistema funcional.

### Descrição das pastas e arquivos

**`README.md`**

Arquivo principal do repositório, responsável por apresentar o projeto, seus integrantes e orientar a navegação pelos documentos.

**`04-dados/`**

Pasta destinada à documentação técnica e aos modelos de dados do TaskFlow.

Os arquivos estão organizados da seguinte forma:

| Arquivo | Conteúdo |
|---|---|
| `00_catalogo_rn.md` | Catálogo das regras de negócio identificadas no cenário. |
| `01_inventario_dados.md` | Identificação e descrição dos dados necessários ao projeto. |
| `02_modelo_conceitual_v1.pdf` | Diagrama do modelo conceitual. |
| `03_decisoes_modelagem.md` | Registro das decisões e justificativas de modelagem. |
| `04_modelo_logico_v1.pdf` | Representação do modelo lógico relacional. |
| `05_dicionario_dados_v1.md` | Descrição dos atributos, tipos de dados e restrições das tabelas. |
| `06_regras_integridade_v1.md` | Especificação das regras de integridade e restrições de domínio. |
